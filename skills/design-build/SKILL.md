# Design Build

Read the [design contract](../design/references/design-contract.md), [principles](../design/references/design-principles.md), [quality](../design/references/quality.md), and relevant [integrations](../design/references/integrations.md). Follow the Dev integration before production edits or new validation.

## Build And Refine

Inspect the project and affected interface, content, states, tokens, components, and assets. Resolve consequential ambiguity through [design-intent](../design-intent/SKILL.md). Use [design](../design/SKILL.md)'s Shape mode when direction needs work; reuse the established direction for settled edits.

Implement the accepted scope under Dev, reusing project/platform capabilities and relevant specialist guidance. Apply visual and usability principles to task needs; preserve explicit style constraints and content.

Run suitable existing checks and inspect rendered states and interactions. Self-inspect and improve material gaps under the shared quality loop, then recheck affected results. Report the result and any remaining delivery or quality limitation using its completion rule.
