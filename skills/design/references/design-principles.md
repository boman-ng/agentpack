# Two-Book Decision Matrix

Apply the relevant lenses to concrete design choices. These frontend applications draw on the linked excerpts and previews of Steve Krug's *Don't Make Me Think, Revisited* and Robin Williams's *The Non-Designer's Design Book*.

| Lens and source | Decision it can change | Evidence to inspect |
|---|---|---|
| Krug: remove avoidable ambiguity ([excerpt](https://www.peachpit.com/articles/article.aspx?p=2209309)) | Replace an obscure label or uncertain affordance with language and cues suited to the audience. Preserve deliberate play where the user's goal calls for it. | At the actual entry state, can a user locate the main action and distinguish an action from decoration? Identify the exact label or cue creating doubt. |
| Krug: make choices understandable ([excerpt](https://www.peachpit.com/articles/article.aspx?p=2170656)) | Explain real alternatives at the decision point; remove needless categorization. Do not optimize click count by combining distinct confusing choices. | Follow a realistic task through the choice. Check that labels predict the destination or result, and guidance is available when needed. |
| Krug: express hierarchy ([excerpt](https://www.peachpit.com/articles/article.aspx?p=2209310)) | Give task-important content prominence; show similarity and containment through visual relationships. | Inspect the rendered scan order and grouping, including a relevant narrow state. Does prominence match task priority rather than decoration? |
| Krug: observe users early ([excerpt](https://www.peachpit.com/articles/article.aspx?p=2209313)) | Seek a useful early task observation when available, before hardening an assumption into an expensive design. | Record actual hesitation, mistaken choices, or missed content from authorized observation. Agent review is a hypothesis source, not real-user evidence. |
| Williams: proximity ([preview](https://www.oreilly.com/library/view/the-non-designers-design/9780133966350/ch02.html)) | Bring related labels, controls, and content together; separate unrelated groups without hiding required information. | Inspect whether spacing communicates the correct membership at relevant sizes and content lengths. |
| Williams: alignment ([preview](https://www.oreilly.com/library/view/the-non-designers-design/9780133966350/ch03.html)) | Establish intentional shared edges or axes instead of arbitrary placement; a deliberate exception must serve the composition. | Check rendered text, control, and image relationships, including wrapping. Name the edge or axis that fails. |
| Williams: repetition ([excerpt](https://www.peachpit.com/articles/article.aspx?p=2268752)) | Reuse a meaningful visual language across related elements and states, using existing tokens/components where suitable. | Compare equivalent roles across the affected views. Confirm consistency expresses relationship without making unlike roles indistinguishable. |
| Williams: contrast ([preview](https://www.oreilly.com/library/view/the-non-designers-design/9780133966350/ch05.html)) | Make meaningful differences clear through appropriate size, weight, shape, spacing, or color instead of weak accidental variation. | Inspect whether primary/secondary roles and states are distinguishable. Check project accessibility requirements separately; visual interest alone is insufficient. |
| Williams: type relationships ([type preview](https://www.oreilly.com/library/view/the-non-designers-design/9780133966350/ch10.html), [type contrast preview](https://www.oreilly.com/library/view/the-non-designers-design/9780133966350/ch12.html)) | Choose coherent or clearly contrasting type roles that explain organization; avoid unintentional near-matches. | Inspect actual copy, hierarchy, readability, wrapping, and available font rendering. A specimen or chosen font name does not prove the result. |
| Williams: deliberate color ([preview](https://www.oreilly.com/library/view/the-non-designers-design/9780133966350/ch07.html)) | Choose purposeful color relationships suited to the brand and output medium; connect palette decisions to emphasis and organization. | Inspect the actual output and adjacent colors. Verify relevant legibility and state communication rather than assigning unsupported emotional meanings. |

Example: unrelated settings groups appear connected because internal and external spacing match. Apply proximity by separating the groups, retaining all settings, then inspect the form with long labels and a narrow viewport.
